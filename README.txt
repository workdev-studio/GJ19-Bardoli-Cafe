# GJ19 The Bardoli Café website

## Run locally
Open `index.html` in a browser. Internet connection is needed for Google Fonts, remote food photos, and the embedded map.

## Included
- Responsive café landing page
- Menu categories and sample add-to-cart
- WhatsApp order message to +91 6355440598
- Google Maps embed and directions
- Phone call link

## Before publishing or showing this as the restaurant's official website
1. Get the owner's approval to use the restaurant name, logo, photos and menu.
2. Confirm menu items, prices, opening hours, address and WhatsApp number.
3. Replace sample stock food images with the café's own approved photos.
4. Confirm whether the café accepts WhatsApp orders. Cart is a WhatsApp enquiry, not a payment or live ordering system.
5. The menu and prices in this demo are based on publicly listed menu information and may change.

This is an independent demo concept, not an official website or an affiliation claim.
